# Project Launcher

本地多项目一键启停面板：**一项目一开关**。

## 背景

本地常常会同时维护多个前端仓库。联调时每次都要开终端、进入目录、确认包管理器，再执行启动命令；项目一多就很难记住谁在跑、命令是什么、日志在哪个窗口。切换网络后本机 IP 变化，已启动的 dev server 往往还绑着旧地址，又得逐个重启。

这个工具会扫描指定工作目录，由你**选择要监听的项目**，再列成面板：**打开开关即启动，关闭即停止**；需要刷新网络绑定时，用「重启运行中」批量拉起当前已启动的项目。

功能刻意保持克制，只解决「选得到、开得了、关得掉、换网能重启」。本地项目名单写在 `config.json`（已 gitignore），不会提交到仓库。

## 功能

- **命令行 `pl`**：任意目录按项目名启停，不用关心仓库路径
- **选择监听**：系统文件夹选择器，可添加「项目集合目录」或「单个项目」；列表可移除项目
- 一项目多开关：命令可同时运行（如 `dev` + `preview:ui`）；关掉哪个停哪个
- **命令设置**：为每个项目配置默认命令，并增删其他快捷命令（默认折叠不展示）
- **打开终端**：在 macOS Terminal 中打开项目目录，直接手动输入命令
- 实时日志、搜索过滤
- **重启运行中**：应对网络 IP 变更

## 使用

首次安装（只需一次）：

```bash
cp config.example.json config.json
pnpm install
pnpm link
```

之后任意目录直接：

```bash
pl                      # 启动面板并打开浏览器
pl ls                   # 列出项目
pl start miniprogram    # 按名字启动，不用管路径
pl start miniprogram build:mp
pl stop miniprogram
pl restart              # 重启全部运行中
```

名字支持简称：能唯一匹配即可（例如 `miniprogram`、`workbench`）。

也可以仍用 `pnpm start` 在本仓库前台跑面板：http://127.0.0.1:3920

打开面板后点「选择监听」：

- **选择项目集合目录**：例如包含多个仓库的父目录，自动识别其下可启动项目
- **选择单个项目**：直接选某个仓库目录

| 操作 | 说明 |
| --- | --- |
| `pl` / `pl start <名字>` | 终端按名字启停，不用进项目目录 |
| 选择监听 | 用系统文件选择器添加 / 移除目录 |
| 命令 | 设置默认命令，添加 / 删除快捷命令 |
| 打开终端 | 新开 macOS Terminal 会话并进入项目目录，可直接手动输入命令 |
| 其他命令 | 展开后用额外开关启停（默认收起） |
| 打开 / 关闭开关 | 启动 / 停止对应命令，可同时开多个 |
| 日志 | 查看输出 |
| 移除 | 从面板列表去掉该项目 |
| 重启运行中 | 重启当前已启动项目 |

点击项目右侧的「打开终端」，会打开独立终端会话并进入该项目目录。首次使用时，macOS 可能会询问是否允许控制 Terminal，允许后即可使用。手动执行的命令由终端管理，面板开关和日志只管理通过面板启动的命令。

更新后台代码后，需要重启面板服务才能加载新接口；只刷新网页或执行 `pl open` 不会重启后台。旧后台缺少终端接口时，按钮会提示重启服务。

## 配置

`config.json` 仅本地使用（gitignore）。由面板写入，一般无需手改：

| 字段 | 说明 |
| --- | --- |
| `collections` | 项目集合目录绝对路径列表 |
| `singles` | 单个项目绝对路径列表 |
| `hidden` | 从集合中隐藏的项目路径 |
| `exclude` | 集合目录下要排除的文件夹名 |
| `commands` | 每项目命令配置：字符串，或 `{ default, shortcuts }` |
| `port` | 面板端口 |

`commands` 示例：

```json
{
  "commands": {
    "some-miniprogram": {
      "default": "build:mp",
      "shortcuts": ["dev", "test:mp"]
    }
  }
}
```

也支持旧写法：`"some-miniprogram": "npm run build:mp"`。

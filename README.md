# Project Launcher

本地多项目一键启停面板：**一项目一开关**。

## 背景

本地常常会同时维护多个前端仓库。联调时每次都要开终端、进入目录、确认包管理器，再执行启动命令；项目一多就很难记住谁在跑、命令是什么、日志在哪个窗口。切换网络后本机 IP 变化，已启动的 dev server 往往还绑着旧地址，又得逐个重启。

这个工具会扫描指定工作目录，由你**选择要监听的项目**，再列成面板：**打开开关即启动，关闭即停止**；需要刷新网络绑定时，用「重启运行中」批量拉起当前已启动的项目。

功能刻意保持克制，只解决「选得到、开得了、关得掉、换网能重启」。本地项目名单写在 `config.json`（已 gitignore），不会提交到仓库。

## 功能

- 扫描工作目录中的可启动项目
- **选择监听**：勾选要出现在面板上的项目
- 一项目一开关：启动 / 停止
- 实时日志、搜索过滤
- **重启运行中**：应对网络 IP 变更

## 使用

```bash
cp config.example.json config.json
# 编辑 config.json 里的 root 为本机项目目录

pnpm install
pnpm start
```

打开 http://127.0.0.1:3920 → 点「选择监听」勾选项目 → 用开关启停。

| 操作 | 说明 |
| --- | --- |
| 选择监听 | 勾选要管理的项目（写入本地 config） |
| 打开 / 关闭开关 | 启动 / 停止 |
| 日志 | 查看输出 |
| 重启运行中 | 重启当前已启动项目 |

## 配置

`config.json` 仅本地使用。示例见 `config.example.json`：

| 字段 | 说明 |
| --- | --- |
| `root` | 项目根目录 |
| `port` | 面板端口 |
| `exclude` | 排除目录（支持 `*`） |
| `watch` | 已选监听的项目名列表 |
| `commands` | 可选，覆盖某项目的启动命令 |
